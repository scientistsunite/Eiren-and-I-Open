# Archive Reader

**Intended use:** View, search, navigate and revisit locally exported ChatGPT conversation archives, including large histories. It is designed for exploring a personal archive without requiring a live ChatGPT session to read an existing export.

**Public repository status:** The implementation source is not yet included in this app's Git tree. Existing releases use the historical package name **ChatGPT Archive Viewer**: a portable Python-based Windows archive and Ubuntu .deb/portable options. See [Releases](https://github.com/scientistsunite/Eiren-and-I-Open/releases) for exact assets and checksums. The placeholders below are not the complete source of those packages.
