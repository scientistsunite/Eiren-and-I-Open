# System Chronicle

**Intended use:** Keep a local timeline of computer activity and performance/thermal readings, such as CPU usage, GPU readings, temperatures and fan speeds where available, to investigate overheating, unusual load or resource trends. Sensor availability and accuracy depend on the hardware and operating system.

**Public repository status:** Implementation source is not in this Git tree. [Releases](https://github.com/scientistsunite/Eiren-and-I-Open/releases) contain historical Windows installer and Ubuntu installable packages. The directories below are currently placeholders, not the released source.

## Reserved platforms

- [Windows](Windows/) — placeholder; historical Windows installer available.
- [Ubuntu](Ubuntu/) — placeholder; historical Ubuntu package available.
- [macOS](macOS/) — placeholder, not a support commitment.
