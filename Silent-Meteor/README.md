# Silent Meteor

**Intended use:** Add a quiet, customizable animated meteor effect to a computer's idle display or screensaver. It is intended for ambient visuals, with configurable meteor behavior and—where a particular version supports it—images and videos as screensaver content.

**Public repository status:** The app's implementation source is not in this Git tree. [Releases](https://github.com/scientistsunite/Eiren-and-I-Open/releases) contain Windows installer/portable and Ubuntu installable distributions. Those downloaded assets are distinct from the platform placeholders below; check each release for actual features and files.
